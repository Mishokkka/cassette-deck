# Cassette Deck

`v1.1.4` — модуль кассетного плеера для Foundry VTT v13.351. Он предоставляет общий виджет игрокам, библиотеку кассет для GM, синхронное воспроизведение, права управления, кассетные аудиоэффекты и диагностическую панель.

Модуль системно-независим и используется с Forbidden Lands v13.0.5.

## Основные возможности

- Библиотека кассет с дорожками, заметками, тегами, сортировкой и доступом по пользователям или ролям.
- JSON import/export с предварительным diff и автоматической резервной копией перед заменой библиотеки.
- Общий transport: play, pause, stop, seek, next/previous, eject, volume, open/close lid и select cassette.
- Детерминированный authority-GM. При нескольких активных GM источник истины выбирается одинаково на всех клиентах.
- Авторизованные клиентские запросы через socketlib. Небезопасный raw socket не используется.
- Сетевая авторизация совместима с локальной игрой по обычному HTTP: идентичность отправителя берётся из socketlib/Foundry transport context, модуль не требует WebCrypto, HTTPS или secure context.
- Атомарный world deck state: команда воспроизведения хранится вместе с соответствующим состоянием и revision.
- Проверка порядка команд по authority epoch, playback sequence, sequence и revision.
- Синхронизация позиции с учётом playback rate и сетевой задержки.
- Серверный контроль естественного окончания дорожки и автоматический переход к следующей.
- Native Audio с fade-in/fade-out, детерминированными wow/flutter, шумом и выпадениями сигнала.
- Audible shuttle-перемотка с отдельным ограниченным усилением. Один клик REW/FWD перематывает на 10 секунд, двойной на 30 секунд.
- Отдельная общая громкость деки и личная громкость/отключение звука на каждом клиенте.
- Кнопка библиотеки в левом верхнем углу открывает локальный список кассет, не меняя состояние крышки.
- Физическая кнопка `OPEN` открывает крышку и одновременно показывает библиотеку; закрытие крышки не закрывает библиотеку.
- Клавиатурное управление регулятором громкости.
- Metadata preload с ограничением кеша и конкурентности, повторными попытками после ошибок и точечной инвалидизацией.
- Кеш нормализованной библиотеки по revision и переиспользование media-элемента перемотки уменьшают лишние аллокации.
- Таймер дисплея работает с частотой 5 Гц только во время воспроизведения, без постоянного 60 Гц `requestAnimationFrame`-цикла.
- Application V2 окна библиотеки, прав, диагностики и настройки SFX.
- Диагностика authority, socket-сессии, deck state, audio runtime, preload и целостности библиотеки.
- Ручной GM-калибратор зон player-v2.

## Совместимость

- Foundry VTT: минимум v13, проверяемая версия manifest — v13.351.
- Forbidden Lands: v13.0.5 в целевом окружении.
- Требуется активный модуль `socketlib`.

## Установка

1. Удалить старую папку `Data/modules/cassette-deck`.
2. Распаковать архив так, чтобы файл `module.json` находился по пути `Data/modules/cassette-deck/module.json`.
3. Запустить Foundry и включить `socketlib` и `Cassette Deck` в мире.
4. Перезагрузить мир после обновления с предыдущей версии. Миграция выполняется автоматически только authority-GM.

## Быстрые команды

```js
await game.cassetteDeck.openWidget();
await game.cassetteDeck.openLibrary();
await game.cassetteDeck.openPermissions();
await game.cassetteDeck.openDiagnostics();
await game.cassetteDeck.requestSync({ reason: "macro" });
```

Управление transport из макроса:

```js
await game.cassetteDeck.transport("play");
await game.cassetteDeck.transport("pause");
await game.cassetteDeck.transport("seekForward", { seconds: 10 });
```

## Настройки

World settings управляют автозапуском виджета, sync pulse, эффектами, fade, preload, общей библиотекой, deck state и правами.

Client settings:

- `Личная громкость` — множитель громкости только на текущем клиенте.
- `Личное отключение звука` — локальный mute без изменения общей ручки деки.

## Библиотека и импорт

Редактор предупреждает о несохранённых изменениях при переключении кассеты, создании новой записи, импорте и закрытии окна. Сохранение использует revision check и единый authority-GM write queue. Если библиотека была изменена другим GM-окном или клиентом, конфликт будет отклонён вместо молчаливого перетирания данных.

Импорт показывает количество добавляемых, удаляемых и сохраняемых по ID кассет. Перед заменой текущая библиотека скачивается отдельным backup JSON.

Поддерживаются локальные Foundry-пути к аудио с расширениями:

```text
ogg, oga, mp3, wav, flac, webm, m4a, aac
```

Пути с traversal, URI-схемами и неподдерживаемыми расширениями отклоняются.

## Калибровка player-v2

Кнопка с линейкой в GM-виджете включает режим ручной настройки зон. В нём можно перемещать и изменять размер экрана, громкости, кнопок, кассеты, названия и крышки. Override сохраняется в world setting `playerLayoutOverride`.
